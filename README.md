# ⚡ H7YN Proxy Scraper ⚡

## 🚀 Key Features
* 🛰️ **Protocol Support:** Scrape and check HTTP, SOCKS4, and SOCKS5.
* ⚡ **Multi-Threaded:** Uses 50 concurrent worker threads for ultra-fast validation.
* 🛠️ **Format Selector:** Choose between `protocol://ip:port` or `ip:port` for your output files.
* 🛡️ **DNS Leak Protection:** SOCKS5h integration ensures secure remote DNS resolution.
* 🎨 **Clean UI:** Professional ASCII banner and organized menu system.


#📝 Step-by-Step Installation Guide

🐍 Install Python

Go to Python.org and download the latest version for your OS.

CRITICAL: During installation, check the box that says "Add Python to PATH". This allows you to run Python from any terminal window.

📁 Project Setup

Create a new folder on your computer.

Install and drag main.py in the folder.

Install and drag requirements.txt in the folder.

📦 Install Requirements

Open your terminal (Command Prompt or PowerShell on Windows).

Navigate to your folder.

Run this command to install the necessary libraries: pip install -r requirements.txt

🚀 Run the Program

Once the libraries are installed, open main.py
